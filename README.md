# 🚀 KariyerAI

**KariyerAI**, kullanıcıların bir iş veya staj ilanına başvurmadan önce CV'lerinin ilana ne kadar uygun olduğunu analiz etmelerine yardımcı olan yapay zekâ destekli bir kariyer aracıdır.

🌐 **Canlı Demo:** https://kariyerai.vercel.app

## 🎯 Projenin Amacı

İş ve staj başvurularında adayların CV'lerini ilanlarla karşılaştırarak güçlü ve geliştirilmesi gereken yönlerini daha kolay görmelerini sağlamak.

Kullanıcı CV'sini PDF formatında yükler ve başvurmak istediği iş veya staj ilanını sisteme ekler. KariyerAI bu bilgileri analiz ederek kullanıcıya başvurusu hakkında geri bildirim sağlar.

## ✨ Özellikler

- 📄 PDF formatında CV yükleme
- 💼 İş / staj ilanı ekleme
- 🤖 Yapay zekâ destekli CV ve ilan analizi
- 🎯 Teknik uyum değerlendirmesi
- 📊 ATS uyumluluğu hakkında geri bildirim
- 🧩 Eksik becerilerin belirlenmesi
- 💡 Başvuruyu güçlendirmeye yönelik öneriler
- 🌐 Web üzerinden kolay kullanım

## 🛠️ Kullanılan Teknolojiler

- Python
- Flask
- Yapay Zekâ / LLM entegrasyonu
- HTML / CSS
- Vercel
- Git & GitHub

## 🚀 Kullanım

1. CV'nizi PDF formatında yükleyin.
2. Başvurmak istediğiniz iş veya staj ilanının açıklamasını ekleyin.
3. **CV'mi Analiz Et** butonuna basın.
4. Yapay zekâ tarafından oluşturulan kariyer analizini inceleyin.
